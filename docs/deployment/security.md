# Security Policy

## Supported Versions

Currently, only the latest version of YouTube Search is supported with security updates.

| Version | Supported          |
| ------- | ------------------ |
| latest  | :white_check_mark: |

## Reporting a Vulnerability

We take the security of YouTube Search seriously. If you believe you have found a security vulnerability, please do not open a public issue. Report it privately via the channel in the repository's [SECURITY.md](../../SECURITY.md) (GitHub Security Advisories).

### What to expect

- We will work with you to understand the scope and impact of the issue.
- We will keep you informed of our progress as we work on a fix.
- We will provide a public disclosure of the vulnerability once a fix is available, giving you credit for the discovery if you wish.

Thank you for helping keep YouTube Search secure!
