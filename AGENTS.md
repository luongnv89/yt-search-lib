# AGENTS.md

Agent-facing guidance for working in this repository. The install/build/test
command block and environment contract are defined once in `CLAUDE.md` (from
the Pre.1 notes in `docs/development/agent-environment.md`) — use those
commands verbatim; this file deliberately does not repeat them.

## Project

- `yt-search-lib` — client-side YouTube search library on InnerTube API
  patterns. No API key, zero runtime dependencies.
- `src/` is the source of truth; the published bundle under `dist/` is
  generated by the build script — never edit it by hand.
- Invariant: the offline unit suite must keep running with no network and no
  credentials. Anything needing live YouTube stays behind the manual
  `test:integration*` scripts.

## Commands

- Defined once in `CLAUDE.md` — install, build, offline tests, lint, format
  check, local CORS proxy. Do not substitute ad-hoc alternatives.

## Layout

- `src/index.js` — public entry; `src/lib/` — internals (`cache.js`,
  `constants.js`, `parser.js`, `transport.js`).
- `src/types.js` — type surface shipped as `dist/index.d.ts`.
- `test.js` — offline unit suite; `integration*.test.js` — live-network
  checks (manual only).
- `proxy-server.js` — local CORS proxy; `build.js` — esbuild script;
  `index.html` — browser demo.
- Docs under `docs/` (`API.md`, `ARCHITECTURE.md`, `development/`, …).

## Conventions

- ES modules only (`"type": "module"`); keep the `dist/index.js` export
  contract (`main`/`module`/`types`) stable.
- Branches `<type>/<issue>-<desc>`; Conventional Commits
  `type(scope): description (#N)`; minimal diffs.
- Pre-commit hook runs the format check and lint — run the formatter before
  committing if either fails.

## Constraints

- Never commit `.env` or edit `dist/`/`package-lock.json` by hand.
- Don't push or commit to `main` — feature branch plus PR.
- No new runtime dependencies: the library is deliberately dependency-free;
  dev-tooling additions go in `devDependencies` and need a reason.
- Public API changes must stay backward compatible or be called out in the PR.

## Done when

- Format check, lint, and the offline unit suite all pass — exact commands in
  `CLAUDE.md`.
- New behavior is covered in `test.js`; if the change ships in the bundle,
  `dist/` was rebuilt via the build script.

## Read when needed

- Environment setup, command table, integration-test caveats → `CLAUDE.md`
  and `docs/development/agent-environment.md`
- Public API → `docs/API.md`; internals → `docs/ARCHITECTURE.md`
- Contributing → `CONTRIBUTING.md`; deployment → `docs/DEPLOYMENT.md`

## Token Efficiency

- Never re-read files you just wrote or edited. You know the contents.
- Never re-run commands to "verify" unless the outcome was uncertain.
- Don't echo back large blocks of code or file contents unless asked.
- Batch related edits into single operations. Don't make 5 edits when 1 handles it.
- Skip confirmations like "I'll continue..." Just do it.
- If a task needs 1 tool call, don't use 3. Plan before acting.
- Do not summarize what you just did unless the result is ambiguous or you need additional input.
